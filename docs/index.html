    Getting good results

    • Fixed camera only: a tripod or fence mount that doesn't move during play. For chest or head cameras, use POV mode in the Python version.
    • Height matters most. 2–3 m up behind a baseline lets the ball and far players be seen.
    • Use the 1× lens at 60 fps if you can, and lock focus and exposure.
    • Live analysis runs a small model on the device, so it's less accurate than the Python pipeline on recorded video.
